Text tasks

To familiarise yourself with the text outputs of maaslin3() please attempt the below tasks. This involves answering some MCQs (multiple choice questions) and creating some of your own code.

Significant results

Please attempt the below MCQs based on the significant results table.

You can find the results by searching through the HTML we created earlier (significant_results.html). The instructions on how to use the html file are here: Explore HTML table.

You can also find the answers using various tidyverse functions on the sig_res_tbl object.

Arranging questions

The first three questions can be carried out by ordering the specific columns by clicking on the column name in the HTML. Optionally, dplyr::slice() functions and the dplyr::pull() function can be used.

  1. Which feature/genus has the most significant q-value for one of its associations?
  1. Which feature/genus has the largest coefficient value?
  1. Which feature/genus has the lowest N_not_zero value?
NoteMCQ1 code 
#MCQ1
#Feature with most significant q-value
sig_res_tbl |>
    dplyr::slice_min(qval_individual, n=1) |>
    dplyr::pull(feature)
NoteMCQ2 code 
#MCQ2
#Feature with largest coefficient value
sig_res_tbl |>
    dplyr::slice_max(coef, n=1) |>
    dplyr::pull(feature)
NoteMCQ3 code 
#MCQ3
#Feature with lowest N_not_zero
sig_res_tbl |>
    dplyr::slice_min(N_not_zero, n=1) |>
    dplyr::pull(feature)

Specific comparisons questions

The next three question involve looking up the results of a specific feature and association. This can be carried out with the search bar in the HTML. With tidyverse you can use multiple dplyr::filter() functions and the dplyr::pull() function.

  1. What is the coefficient value of Kribella for the Rhizosphere Soil vs Bulk Soil comparison for the abundance model?
  1. What is the coefficient value of Bordetella for the Rhizosphere Soil vs Bulk Soil comparison for the prevalence model?
  1. What is the coefficient value of Azospira for the reads association for the prevalence model? 
#MCQ4
#Coefficient value of Kribbella for Soil comparison
# for the abundance model
sig_res_tbl |>
    dplyr::filter(feature=="Kribbella") |>
    dplyr::filter(name=="SoilRhizosphere Soil") |>
    dplyr::filter(model=="abundance") |>
    dplyr::pull(coef)
#MCQ5
#Coefficient value of Bordetella for Soil comparison
# for the prevalence model
sig_res_tbl |>
    dplyr::filter(feature=="Bordetella") |>
    dplyr::filter(name=="SoilRhizosphere Soil") |>
    dplyr::filter(model=="prevalence") |>
    dplyr::pull(coef)
#MCQ6
#Coefficient value of Azospira for Reads association
# for the prevalence model
sig_res_tbl |>
    dplyr::filter(feature=="Azospira") |>
    dplyr::filter(name=="Reads") |>
    dplyr::filter(model=="prevalence") |>
    dplyr::pull(coef)

All results

For this task you will read in the all results file as a tibble.

  • File to read in: genu_output/all_results.tsv
  • Output tibble name: all_res_tbl
  • Glimpse the tibble once it is created
  • Create a HTML table file with the contents of all_res_tbl
  • Use the instructions for the significant results as a guide: sig results page
  • Feel free to copy and paste your previous code but ensure you edit/change the relevant names

Answer the below MCQs based on the sig_res_tbl and all_res_tbl objects.

  1. How many observations are there in the significant results table?
  1. How many observations are there in the all results table? 
#Read in all results
all_res_tbl <- readr::read_delim(
    file = "./genus_output/all_results.tsv", 
    delim="\t")
all_res_tbl |> glimpse()
#Create HTML object
all_res_dt <- DT::datatable(all_res_tbl, options = list(pageLength = 20))
#Save HTML
htmlwidgets::saveWidget(
    #Input widget/html
    widget = all_res_dt,
    #Output html
    file = "./genus_output/all_results.html",
    #Save as a single self contained HTML
    selfcontained = TRUE)
NoteTable too big

In your future research you may have a table that is too big to convert to a HTML with DT::datatable(). If this is the case you’ll get the following warning:

Warning message in instance$preRenderHook(instance):
“It seems your data is too big for client-side DataTables. You may consider server-side processing: https://rstudio.github.io/DT/server.html”

Unfortunately the link in the suggestion is dead. Most likely trying to setup server-side processing will be incredibly difficult and not worth the effort to view all the results as an HTML. Therefore, you’ll need to look at the table through an R tibble or possibly through excel.
